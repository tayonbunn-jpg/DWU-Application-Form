# 🎓 Divine Word University Online Admission Portal

A modern, responsive web-based admission portal developed as part of the **MC409 Human Computer Interaction (HCI)** course at **Divine Word University**.

This project is a redesign of the traditional **DWU Non-School Leaver Application Form**, transforming the paper-based application into an interactive and user-friendly online admission system.

---

## 📌 Project Overview

The portal demonstrates how university admission processes can be digitized to improve accessibility, usability, and efficiency. It follows modern web design principles and provides applicants with a professional interface for completing and submitting their application.

---

## ✨ Features

- Responsive and modern user interface
- Professional navigation bar
- DWU branding with logo
- Multi-step application form
- Progress bar indicating application status
- Applicant personal information section
- Academic information section
- Work experience section
- Supporting document upload
- Form validation using JavaScript
- Simulated **SevisPass Digital Identity Verification**
- Applicant declaration
- Responsive design for desktop, tablet, and mobile devices
- Smooth animations and user-friendly interactions
